## 📌 Overview

This project is a simple beginner-friendly guide to understanding how `ArrayList` works in Java.

It demonstrates the most common `ArrayList` operations step-by-step:

- ➕ Adding elements
- ✏️ Replacing elements
- ❌ Removing elements
- 🧹 Clearing the list

The purpose of this repository is to help students and beginners learn how dynamic arrays work in Java compared to normal arrays.

---

## 🎯 Goal

- 📚 Help beginners understand Java `ArrayList`
- 🧠 Demonstrate basic `ArrayList` operations clearly
- 💻 Provide a simple reference for learning collections in Java
- 🚀 Build a strong foundation before learning advanced data structures

---

## ✨ Features

- ➕ Add elements using `add()`
- ✏️ Replace elements using `set()`
- ❌ Remove elements using `remove()`
- 🧹 Clear all elements using `clear()`
- 🔁 Display contents using loops
- 📊 Demonstrates how `ArrayList` changes dynamically

---

## 🧠 How It Works

1. Create an empty `ArrayList`
2. Add animal names into the list
3. Display all elements
4. Replace existing values
5. Remove one element
6. Clear the entire list
7. Print the final output

## ⚙️ Code Structure

```java
ArrayList<String> animals → stores animal names
add() → adds elements
set() → replaces elements
remove() → removes elements
clear() → clears the entire list
size() → gets current size
get() → accesses elements
for loop → displays all elements
```

---

## 🧾 Main Operations

```java
// add
animals.add("dog");

// replace
animals.set(0, "pig");

// remove
animals.remove(2);

// clear
animals.clear();
```
